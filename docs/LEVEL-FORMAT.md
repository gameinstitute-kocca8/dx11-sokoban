# 레벨 파일 형식

널리 쓰이는 소코반 텍스트 형식(XSB)을 그대로 씁니다. UTF-8 텍스트 파일입니다.

| 문자 | Terrain | Occupant | 3D에서의 표시 (08단계~) |
|---|---|---|---|
| `#` | Wall | Empty | 회색 벽 큐브 |
| ` ` 또는 `-` | Floor | Empty | 바닥 |
| `.` | Goal | Empty | 파란 목표 |
| `@` | Floor | Player | 플레이어 (빨간 시작 칸) |
| `+` | Goal | Player | 목표 위의 플레이어 |
| `$` | Floor | Crate | 상자 |
| `*` | Goal | Crate | 목표 위의 상자 |

- `;`로 시작하는 줄은 주석입니다.
- 줄 길이가 달라도 됩니다. 짧은 줄의 나머지는 바닥으로 채웁니다.
- 플레이어는 정확히 1개여야 합니다.
- 맵 밖은 벽으로 취급합니다.

## 좌표계

```text
x →  0 1 2 3 4
y 0  # # # # #
↓ 1  # @ $ . #
  2  # # # # #
```

- `x`는 오른쪽이 +, `y`는 아래쪽이 +입니다. 텍스트의 첫 줄이 `y = 0`입니다.
- 3D 월드 좌표로의 대응(예: `y`를 `-z`로 둘지)은 08단계에서 정합니다.

## 상태는 두 층

```text
Terrain  : Floor / Wall / Goal       (움직이지 않음)
Occupant : Empty / Player / Crate    (움직임)
```

"목표 위의 상자"는 별도 종류가 아니라 `Goal + Crate`의 조합입니다.
