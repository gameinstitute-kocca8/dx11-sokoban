# 14 A* Grid

## 목표

13단계의 A\*를 소코반 맵에 연결합니다. **오른쪽 클릭한 칸까지 플레이어가 자동으로 걸어갑니다.** 상자는 밀지 않고 피해 갑니다. A\*가 탐색한 칸(청록 점)과 찾은 경로(노란 칸)를 3D로 보여 줍니다.

## 배울 개념

- **알고리즘과 게임의 경계:** A\*(`Game/AStar.*`)는 "막힌 칸"만 압니다. 무엇이 막힌 칸인지(벽, 상자)는 게임 쪽(`Game/PathFinder`)이 정합니다. 그래서 13단계 코드를 고치지 않고 가져다 씁니다.
- **경로 → 입력:** 찾은 칸 목록을 방향 목록으로 바꾸고, 키 입력과 **같은** `game_.Move`로 한 칸씩 실행합니다. 이동 횟수, Clear, Undo가 그대로 동작합니다.
- **계획과 실행의 분리:** 클릭할 때 한 번 계획(A\*)하고, 매 프레임 조금씩 실행합니다. 키보드로 움직이면 계획을 버립니다.
- **피킹(제공 코드):** 마우스 픽셀 → 광선 → 바닥 평면과 만나는 점 → 칸. `Game/Picking.cpp`를 읽어 보세요.
