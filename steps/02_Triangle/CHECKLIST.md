# 02 통과 조건

## 동작

- [ ] 기대 화면과 같은 삼각형
- [ ] 출력 창에 `[실패]`나 디버그 레이어 오류가 없음
- [ ] 예측 질문 4개를 실제로 실험하고 결과를 기록

## 기록

- [ ] SPEC 커밋 → 구현 커밋 순서
- [ ] `LOG.md` 1~2건

## 데모에서 설명할 수 있어야 하는 것

- Input Layout은 왜 **정점 셰이더의 바이트코드**로 만드는가?
- 정점 3개인데 삼각형 내부의 수많은 픽셀 색은 어디서 오는가?
- 화면에 아무것도 안 보일 때 확인할 순서 세 가지 (예: Draw 호출 여부, 뷰포트, 정점 순서)
