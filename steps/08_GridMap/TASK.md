# 08 Grid Map

## 목표

00단계의 레벨 파일과 규칙 코드를 그대로 가져와, **상태(Level)를 3D 맵으로 그립니다.** 아직 움직이지 않습니다.

```text
08_GridMap/
  Render/  Engine/        07단계 그대로
  Game/    Sokoban.*      00단계 규칙 (내 00 코드로 바꿔도 된다)
           GridView.*     상태 → 그리기   ← 이번 과제
           main.cpp       레벨 읽기, 카메라
           levels/        00단계 레벨 파일
```

## 배울 개념

- **상태가 진실이다.** 화면은 매 프레임 `Level`을 읽어 다시 그립니다. 큐브 객체를 따로 만들어 위치를 들고 있지 않습니다.
- **좌표 약속:** 지도 칸 `(x, y)` → 월드 `(x, 0, y)`. 카메라를 지도의 아래쪽(+Z)에 두면 텍스트 지도와 화면의 위/아래/좌/우가 같아집니다. 05단계 예측 질문 2번에서 본 "-Z 쪽에서 보면 +X가 왼쪽"을 피하는 방법입니다.
- **같은 메시, 다른 행렬:** 벽, 바닥, 상자, 플레이어가 모두 같은 큐브입니다. 크기·위치·색만 다릅니다 (04단계).
- **flood fill:** 벽 바깥 빈칸에는 바닥을 그리지 않기 위해, 플레이어에서 갈 수 있는 칸을 찾습니다.
