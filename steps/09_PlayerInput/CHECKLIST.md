# 09 통과 조건

## 동작

- [ ] 키를 한 번 누르면 정확히 한 칸 이동 (꾹 눌러도 한 칸)
- [ ] 상자 밀기와 막힘이 00단계 테스트와 같은 규칙으로 동작
- [ ] 카메라를 0, 90, 180, 270도 돌린 각각에서 W가 화면 위쪽으로 감
- [ ] 시작 화면 캡처가 `expected/09_Sokoban.png`와 같음

## 기록

- [ ] SPEC 커밋 → 구현 커밋 순서
- [ ] `LOG.md` 1~2건

## 데모에서 설명할 수 있어야 하는 것

- 눌린 순간과 눌려 있음의 차이, 그리고 `KeyboardStateTracker`가 하는 일
- 카메라 yaw에서 앞/오른쪽 벡터를 구하는 식
- Input이 Game이 아니라 Engine에 있는 이유 (CubeViewer도 쓸 수 있는가?)
- 막힌 이동에서 상태가 바뀌지 않는다는 보장은 어디에서 오는가? (00단계)
